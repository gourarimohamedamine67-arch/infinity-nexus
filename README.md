# Infinity Nexus

Jeu open-world multivers en **Godot 4.6** (GDScript) : des portails Nexus mènent vers des mondes procéduraux, chacun avec son relief, ses couleurs et son ciel.

## Lancer le jeu
1. Installer [Git LFS](https://git-lfs.com) **avant** de cloner : `git lfs install`
   (les modèles `.fbx` et textures `.png` sont stockés en LFS ; sans lui, Godot ne voit que des fichiers vides).
2. Cloner le dépôt, ouvrir le dossier avec Godot 4.6.
3. Lancer avec **F5** (scène principale : `game.tscn`).

## Contrôles
| Action | Touche |
|---|---|
| Se déplacer | ZQSD (AZERTY) / WASD (QWERTY) ou flèches |
| Courir | Shift |
| Sauter | Espace |
| Caméra | Souris |
| Libérer / reprendre la souris | Échap / clic |

Traverser un portail en marchant dedans téléporte vers un autre monde.
